# Security

## Reporting a vulnerability

Report it privately through [GitHub's vulnerability reporting](https://github.com/mainstaycms/mainstay/security/advisories/new),
never in a public issue or pull request. Say what an attacker can do, and how to reproduce it.

Mainstay has one maintainer, so replies are best effort. Expect an answer within a week. A
confirmed vulnerability is fixed in a release, then published as a GitHub security advisory
with a CVE, crediting the reporter unless they ask not to be named.

## Supported versions

Only the latest minor release receives security fixes.
